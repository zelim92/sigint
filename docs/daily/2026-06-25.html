Cloudflare's 'Copy Fail' Linux LPE Response: eBPF LSM Policy + 48-Hour Log Hunt
A 4-byte out-of-bounds write in Linux's AF_ALG crypto interface allowed unprivileged users to corrupt cached binaries (e.g. /usr/bin/su) and gain root. Cloudflare confirmed existing behavioral detection caught exploit attempts within minutes, hunted 48 hours of logs finding no exploitation, then deployed a bpf-lsm policy restricting AF_ALG socket binds to an allow-list with fleet-wide tracing to avoid breaking legitimate users. Response pattern is a strong model for runtime kernel exploit mitigation at scale.

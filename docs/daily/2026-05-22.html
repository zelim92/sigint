CVE-2026-3102: ExifTool RCE on macOS via Metadata Injection in SetMacOSTags
GReAT found that ExifTool ≤13.49 on macOS allows arbitrary command execution when unsanitised DateTimeOriginal metadata flows through SetMacOSTags into a system() call, exploitable by injecting single quotes via the -n flag and copying via -tagsFromFile. Fix in 13.50 replaces string concatenation with list-form system() calls. Any photo-processing pipeline, asset management tool, or bulk image workflow using ExifTool on macOS is exposed until patched.

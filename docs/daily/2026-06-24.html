MCP 'Agentjacking' via Sentry DSN: prompt injection that bypasses EDR, WAF, IAM, and VPN
Researchers demonstrated an attack chain where a publicly exposed Sentry DSN (documented by Sentry as safe to embed) allows an attacker to inject a crafted error event whose markdown fields contain a fake fix section with a malicious npx command. When an AI coding agent (Claude Code, Cursor, Codex) clears the Sentry backlog via MCP, it reads the injected event as trusted guidance and executes the command with the developer's own credentials, reaching AWS keys, GitHub tokens, and git secrets. Because every step is an authorized action, the attack sidesteps EDR, WAF, IAM, VPN, and firewall controls entirely — defenders must gate agent-initiated commands at the runtime layer, not the network or prompt layer.

Ex-Meta L8 principal engineer's complete agentic engineering workflow: terminal-first, agent-agnostic, 30+ PRs/day
Kun Chen (former Meta/Atlassian L8) published a detailed walkthrough of his solo agentic setup: WezTerm + tmux + Neovim as the keyboard-driven shell, Claude Code and OpenCode as agent harnesses (deliberately kept agent-agnostic to avoid vendor lock-in), voice input via local Whisper-class models to beat typing speed, and custom open-source tooling to handle automated code review, PR creation, and parallel worktree management. The core architectural insight is maintaining agent-agnosticism — avoid features like auto-managed memory that lock you to a single vendor since model leadership rotates rapidly. Parallel tmux sessions allow multiple agents running simultaneously on different worktrees, with the engineer operating at spec and review level only.

4 bytes of struct padding yields 49% faster array clearing in Go on Intel due to SIMD alignment
Adding 4 bytes of padding between struct fields in Go can improve array-clearing performance by up to 49% on Intel machines by enabling the processor's optimised SIMD memory instructions that require aligned elements. Misaligned struct fields prevent the CPU's optimised memory handling paths from engaging. A concrete production-level optimisation case study worth benchmarking in high-throughput Go services.

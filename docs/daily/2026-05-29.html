CVE-2026-45695 (CVSS 9.8): Unauthenticated RCE in Kopia backup via SSH ProxyCommand injection
Kopia's /api/v1/repo/exists endpoint passes SFTP config fields unsanitised into an SSH command line, allowing a single crafted HTTP request to inject -oProxyCommand= and execute arbitrary shell code on the backup server. Affects versions ≤0.22.3 when running --without-password on non-loopback interfaces. No public PoC yet but trivially weaponisable. Patch: upgrade to 0.23.0; otherwise restrict to localhost and place behind an authenticating proxy.

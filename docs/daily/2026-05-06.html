Instacart Migrated Search from Elasticsearch to Postgres, Achieving 10x Write Reduction
Instacart replaced Elasticsearch with Postgres for its search infrastructure after Elasticsearch's denormalized document model made billions of daily write updates (price, inventory, availability) catastrophically expensive. A normalized relational model means only the changed table (e.g. price) is touched, reducing write load 10x and enabling hundreds of GB of ML features to be stored alongside search data. The tradeoff: analytical, search, and transactional workloads now share a cluster, creating noisy-neighbor risk.

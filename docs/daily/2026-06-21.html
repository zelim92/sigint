GlassWASM: WebAssembly Malware in Trojanized Open VSX Extensions — Zero Plaintext IOCs
Two Open VSX extensions (ExarGD.vsblack, noellee-doc/flint-debug) contained TinyGo-compiled WASM payloads decrypting strings via embedded ChaCha20 at runtime and using Solana SPL Memo transactions as a dead-drop C2 resolver before executing cross-platform download-and-execute via Node child_process. IOC-based detection is ineffective due to rotating C2; defenders must hunt the execution chain (WASM load → Node child_process → download). Any host that activated these extensions should be treated as fully compromised.

Docker internals: CLI → dockerd → containerd → runc → Linux namespaces/cgroups
ByteByteGo maps the full container startup chain: Docker CLI sends an API call to dockerd, which delegates lifecycle management to containerd, which calls runc to create Linux namespaces and mount the OCI bundle. Keyset and cursor-based pagination outperform offset at scale — practical comparison of four strategies
ByteByteGo compares offset, keyset, continuation-token, and time-based pagination: offset scans all skipped rows so deep pages degrade linearly, while keyset uses indexed lookups making page 1 and page 10,000 equivalent in cost. Continuation tokens (used by S3, YouTube) encapsulate cursor logic server-side but require stable query parameters across pages. Directly applicable to high-volume transaction/audit-log APIs in fintech.

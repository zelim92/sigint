Figma Data Pipeline Overhaul: CDC + Kafka Reduces Latency from 30+ Hours to <3 Hours, Saves Millions in Replica Costs
Figma replaced daily full-table S3 dumps (taking days for large tables) with a custom CDC pipeline using RDS WAL → Kafka → Snowflake incremental merge, cutting data freshness from 30+ hours to under 3 hours (configurable to minutes). Eliminating dedicated export replicas saved millions annually; billing pipeline runs on 30-minute cycles while other tables default to 3-hour merges. The key engineering detail: CDC stream start offset must precede the snapshot timestamp to avoid a silent 2-hour data gap during bootstrap.

DoorDash simulation-evaluation flywheel for LLM chatbot testing at scale
DoorDash built an offline simulation + LLM-as-judge evaluation pipeline to iterate on their customer support chatbot without risking production degradation. An LLM plays the customer role using behavioral profiles derived from real historical transcripts, generating dynamic multi-turn conversations; a separate LLM evaluator scores each conversation against policy criteria with binary pass/fail. The system runs 200+ simulated conversations in under 5 minutes and enforces a 50+ evaluation suite as a gate before any deployment, cutting iteration from days to hours.

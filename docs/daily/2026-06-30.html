ByteByteGo: Production agent memory architecture — four-tier hierarchy and retrieval tradeoffs
Comprehensive engineering breakdown of why LLM statelessness forces externalised memory systems: context windows suffer cost, latency, and 'lost-in-the-middle' attention degradation at scale. Production systems use a four-tier hierarchy (context window → session store → long-term embeddings → cold archive) with working, episodic, semantic, and procedural memory types — the core engineering problem being retrieval (what to promote into the window per turn) rather than storage. Directly relevant to building AI-augmented fraud/IAM systems that need cross-session continuity.

RLVR scaling hits a wall without deterministic simulators; continual learning requires weight updates
Analysis of the current AI paradigm argues that scaling reinforcement learning from verifiable rewards (RLVR) across diverse tasks is the dominant bet for AGI, but the approach breaks in domains lacking deterministic feedback loops (e.g., open-ended reasoning, long-horizon planning). True continual learning — rather than in-context accumulation — requires writing back into model weights, a capability no current production system supports.

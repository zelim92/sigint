GitHub Actions cache poisoning: systemic open-source supply chain risk affecting Angular, tj-actions, TanStack
Cache poisoning allows attackers to write malicious dependency caches that execute inside privileged publish workflows — either directly or by cache eviction using tools like Cacheract, as demonstrated in multiple high-profile incidents. Mitigations: pin actions to SHAs, gate workflow edits with CODEOWNERS, disable or isolate caches in release jobs, enforce non-SMS 2FA, and treat AI agent configs as executable code. If a compromised package ran, remove gh-token-monitor before rotating credentials, then reimage hosts.

UEFI PngDecoderDxe buffer over-read: missing read-side bounds check leaks pre-OS memory including crypto keys
NetSPI found a UEFI PNG decoder validates total allocation size against 0x7fffffff but never bounds-checks reads against compressed data length — spoofing IDAT chunk length to 0x90000000 causes the decompressor to read past the buffer into adjacent pre-OS memory containing cryptographic keys and assembly code. Exploitation is demonstrable via Qiling harness with hooked AllocatePool/FreePool; leaked data is theoretically exfiltrable via HDMI/VGA boot display capture. Audit all UEFI image parsers for read-side bounds checks independent of allocation guards.

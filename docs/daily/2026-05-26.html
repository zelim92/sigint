Apple M5 Memory Integrity Enforcement Bypassed in 5 Days Using Mythos Preview
A three-person team using Anthropic's Mythos Preview produced the first public macOS kernel exploit defeating Apple's Memory Integrity Enforcement on M5 silicon, chaining CVE-2026-28952 with an info leak to reach a root shell in five days. The root cause is an integer overflow in `_zalloc_ro_mut` — the sole trusted writer for read-only kernel zones — that spills attacker-controlled bytes across slot boundaries and flips cr_uid to zero without touching pointers, tags, or page tables. This reframes hardware memory tagging as shifting rather than eliminating the attack surface, with privileged writers now the highest-value target.

CockroachDB C-SPANN: Distributed Vector Index Stored as Native Table Data
CockroachDB's C-SPANN builds a hierarchical K-means tree where each partition is stored as ordinary key-value rows within CockroachDB ranges, inheriting existing split, rebalance, caching, and multi-region machinery for free. This avoids the central coordinator, large in-memory caches, and sharding-hostile layouts that disqualify HNSW and IVF for distributed transactional systems. Trade-off: C-SPANN loses on pure latency to specialized in-memory vector DBs but wins on transactional consistency, real-time updates, and multi-tenant isolation.

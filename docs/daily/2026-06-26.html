Mechanistic explanation of prompt injection: models assess authority by text style, not role tags
A LessWrong post provides a mechanistic account of why LLMs remain vulnerable to prompt injection: models learn to assess authority from writing style and content rather than from structural role tags (user/assistant/think), making it trivial to hijack control flow via injected text. This has direct implications for any agentic system that processes untrusted content — the problem is architectural, not patchable with prompt guards alone. Understanding this is prerequisite to designing secure agentic pipelines.

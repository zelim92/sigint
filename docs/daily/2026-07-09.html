Januscape (CVE-2026-53359): 16-year-old Linux KVM use-after-free enables cloud VM escape
A use-after-free in KVM's shadow MMU (present since 2010) lets a guest VM corrupt host kernel memory on Intel and AMD — a public PoC reliably panics the host within seconds, with a more severe path enabling host code execution. Multi-tenant clouds exposing nested virtualization (GCP, AWS custom stacks) are directly threatened; patch immediately or disable nested virt for untrusted guests.

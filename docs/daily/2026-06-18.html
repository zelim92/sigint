Google Vertex AI SDK bucket-squatting flaw allowed malicious model injection via OAuth token theft
A bug in the Vertex AI Python SDK used predictable staging bucket names, letting attackers pre-register them, intercept model uploads from other projects, and substitute malicious pickle-based models that executed arbitrary code in Google's serving containers. Unit 42's test payload stole OAuth tokens and accessed other model artifacts, logs, and metadata in the same Google-managed tenant. Fixed in v1.144.0 (randomized names) and fully patched in v1.148.0 (bucket ownership checks) — upgrade and set explicit staging_bucket everywhere.

Stop using JWTs for sessions: stateless auth is largely a myth
A widely circulated technical argument makes the case that JWTs are inappropriate for user session management — they were never designed for long-lived authentication, and truly stateless token revocation is impractical without a persistent store. Cookie-based sessions with server-side state offer better security properties and flexibility for revocation and expiry. Relevant for any IAM or auth system design review.

Netflix multimodal video search: three-stage pipeline fusing ensemble AI model outputs via temporal bucketing
Netflix built a production video search system that ingests outputs from specialist models (character recognition, scene classification, dialogue transcription, object detection) into Cassandra, fuses them via one-second temporal bucketing with upsert semantics, then indexes enriched nested documents in Elasticsearch for hybrid text+vector queries at sub-second latency. The temporal bucketing design — composite key of asset ID + time bucket — handles incremental model additions and avoids duplicate records at scale (7.2M buckets per 2,000-hour archive). A parallel track is developing MediaFM, a unified foundation model for audio/video/text, but the ensemble pipeline remains the production system.

Netflix multimodal video search architecture: Cassandra ingest → temporal bucket fusion → Elasticsearch nested-document index
The production system decouples three concerns: high-throughput write ingestion to Cassandra (zero transformation), offline async fusion via one-second temporal bucketing with composite-key upserts, and Elasticsearch indexing of hierarchical parent/child documents for hybrid text+vector queries. This separation means complex cross-model intersection never contends with real-time ingestion. The 1-second bucket granularity was chosen as the precision/manageability tradeoff at Netflix's archive scale.

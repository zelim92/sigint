NGINX 18-Year-Old Heap Overflow (CVE-2026-42945) Enables Remote Code Execution
Depthfirst disclosed four remote memory corruption bugs in NGINX including CVE-2026-42945, a heap overflow in the rewrite/set script engine present since 2008 in NGINX and F5 products. A crafted rewrite+set sequence miscalculates buffer length, overflows heap data with escaped URI bytes, and corrupts ngx_pool cleanup pointers to achieve RCE. Exploitation is reliable via deterministic worker heaps and cross-request heap feng shui — urgent patching required for any NGINX deployment using rewrite/set.

AWS Cognito Multi-SSO Attack Patterns: JIT Ghost Injection, Sub-Splitting, IdpIdentifier Hijack
Doyensec documented four concrete attack patterns against AWS Cognito User Pools with tenant-supplied OIDC/SAML IdPs: JIT ghost identity injection via missing PreSignUp domain checks, trigger-source gaps bypassing constraints on first federated login, sub-splitting attacks on ProviderName_sub username parsing, and IdpIdentifier hijacks (e.g., claiming gmail.com). Homoglyph collisions in ProviderName (Cyrillic vs ASCII) further enable split-identity confusion across Hosted UI, audit logs, and Lambda consumers. Defenders must branch PreSignUp logic across all triggerSource values, derive tenant/role server-side, and gate IdpIdentifier claims behind verified domain ownership.

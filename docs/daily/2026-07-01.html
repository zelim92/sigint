DirtyClone (CVE-2026-43503, CVSS 8.8): fourth Linux kernel LPE in six weeks, root via IPsec tunnel
Unprivileged local users can gain root by mapping a privileged binary (e.g. /usr/bin/su) into a packet and forcing decryption through an attacker-controlled IPsec tunnel, overwriting auth logic without disk writes or logs. Requires CAP_NET_ADMIN, available by default on Debian/Fedora via unprivileged user namespaces; Ubuntu 24.04+ blocks via AppArmor. Mitigations: apply May 21 mainline patch, or set kernel.unprivileged_userns_clone=0 / blacklist xfrm modules (disables IPsec/AFS).

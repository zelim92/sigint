Splunk Enterprise CVE-2026-20253 (CVSS 9.8): Pre-Auth RCE via PostgreSQL Sidecar Proxy
The /__raw/v1/postgres/recovery/ proxy exposes a loopback-only PostgreSQL service on port 5435 to the network unauthenticated. Postgres Bulk Delete at Scale: Only DROP TABLE or TRUNCATE Are O(1)
Large DELETE operations in Postgres leave dead tuples, add WAL/replication overhead, and never return disk space — they add work rather than reclaim it. DROP TABLE and TRUNCATE operate directly on file system objects, scaling independently of data size. The practical implication: design schemas so bulk deletion maps to table/partition drops, not row-level deletes, particularly relevant for high-volume event tables, audit logs, or time-series data in fintech systems.
